# HagiiZ 応援サイト（ともプロ！2026）

東北大学主催の選考型クラウドファンディング「ともプロ！2026」No.09 への入口となるサイトです。
GitHub Pages でそのまま公開できます。

## ページ構成と、読む順番

| ファイル | 役割 |
|---|---|
| `index.html` | 入口。**体験（模型）→ 問い → 答え（遊び）→ 3つの物語 → 4つの場 → 私たち → 応援する** の順 |
| `science.html` / `bosai.html` / `doboku.html` | 代表の思いを書いた物語。表紙 →「達成したら、こうなる」→「いちばん伝えたいこと」→ 物語の本文 → 応援の入口、の順。お金の話は出しません |
| `support.html` | 応援ページ。「応援する」を押した人だけが見る、お金・返礼品・寄付のしかた・よくある質問 |

お金の話は `support.html` にだけ置いています。物語やトップの「応援する」は、すべてここに来ます。

## 見る人に起きること

- **模型**：ボタン（または模型そのもの）を押すたびに土砂降りになり、水位が一段ずつ上がります。3回目で堤防を越え、町に水が入ります。Androidでは押した瞬間に振動します。
- **写真がまだ無い枠**は、空欄にせずイラスト（`assets/img/`）で埋めます。写真を `images/` に置くと、そちらに替わります。
- **書体**：見出し・数字は Dela Gothic One。それ以外（言い切りの一文も、説明の文章も）は Noto Sans JP の極太です。説明の太さは `style.css` の `--w-note`（今は900）で変えられます。ふい字はいったん使っていません。
- **倍速モード**：物語ページの「⚡倍速」で、主張と見出しだけになります。`science.html?fast=1` で最初から倍速にもできます。
- **「達成したら、こうなる」**：物語の山場は、達成後の風景のイラストを背景に出します（`assets/img/vision-*.svg`）。写真に替えたいときは `images/<分野>/win.jpg` を置くと、そちらが使われます。
- **土木の物語は Coming soon**：支援額が `UNLOCKS` の金額に届くと、自動で公開されます（支援額は毎朝自動で更新）。
- 寄付ボタン（応援ページのみ）は、10/1より前は「寄付ページを見る（受付は10/1から）」、期間中は「東北大学基金で寄付する」に自動で変わります。

## 本文の書き方（content/*.js）

- `{ ... }` の1つが1つの場面です。`body` の `"..."` が1段落。改行は `\n`。
- **段落まるごと `**…**` で囲むと「主張」**（太いゴシック・マーカー付き）になり、倍速モードでも残ります。
- 段落の一部だけ `**…**` にすると、その部分が太字＋マーカーになります。
- `tldr` は表紙の「3行でいうと」です。
- 〔OO〕のような未記入は、制作中は黄色で目立ち、公開時（`DRAFT: false`）は自動で隠れます。

## 設定（assets/js/config.js）

| 項目 | 内容 |
|---|---|
| `DRAFT` | **ふだんは `false` のまま**。制作中の目印（画像の置き場所・〔OO〕の未記入）は、URLの末尾に `?draft=1` を付けたときだけ出ます（例：`index.html?draft=1`） |
| `UNLOCKS` | 物語を公開する支援額。例 `{ doboku: 500000 }` |
| `FORCE_OPEN` | `true` で鍵のかかった物語も表示（確認用。公開時は `false`） |
| `UNLOCKS` | 物語の公開条件。`{ doboku: 500000 }` なら、50万円達成で土木の物語が開く。`FORCE_OPEN: true` で確認用に全部開く |
| `GOAL` | 目標額。**寄付ページの「目標金額」と必ず揃える** |
| `FUNDS` / `UNITS` | 使い道の内訳と「◯円で◯◯ができる」。寄付ページの記載と揃える |
| `TEAM_GIFT` / `NAME_FORM_URL` | HagiiZからの特典（名前を刻む）と、名前登録フォームのURL |
| `VIDEO` | 挨拶動画（応援ページに出ます）。空のまま公開すると動画の欄ごと隠れます |
| `GA_ID` | Google Analytics 4 の測定ID（任意）。寄付・予定登録ボタンのクリックを位置つきで記録 |

## 支援額の自動更新

`.github/workflows/progress.yml` が毎朝9時半に寄付ページを読み、`data/progress.json` を書き換えます。
サイトはその数字をゲージに使います（寄付ページ側の反映は翌営業日以降です）。

- 初回だけ：リポジトリの **Settings → Actions → General → Workflow permissions** を「Read and write」にしてください。
- すぐ更新したいとき：Actions タブ →「支援額を更新」→ Run workflow。
- 読み取りに失敗しても前回の数字が残るだけで、サイトは壊れません。

`assets/fonts/README.md` を見てください。`tools/subset_font.py` で使う文字だけに絞ると、約3〜4MBが200KB前後になります。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロード（`.nojekyll` と `.github` も含める）。
2. **Settings → Pages** で Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save。
3. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます。
