# ふい字の置き場所

説明の文章（手書き風の部分）には「ふい字」を使います。

1. 配布元「ふい字置き場」からダウンロードして解凍します（.lzh 形式です）。
2. **同梱の利用規約を読み、Webフォントとしてサイトに置いてよいかを確認してください。**
   （商用利用可とされていますが、Webへの埋め込み・再配布の扱いは規約の本文で確認が必要です）
3. `.ttf` を `assets/fonts/src/` に置き、`python tools/subset_font.py` を実行します。
4. `assets/fonts/HuiFont.woff2` ができれば完了です。

- `assets/fonts/src/` の元ファイル（約3MB）は公開しなくて大丈夫です。`.gitignore` で除外しています。
- ここにファイルが無いあいだは、形の近い「Zen Kurenaido」（Google Fonts）で表示されます。
- 見る人の端末にふい字が入っていれば、それが優先して使われます。
